# Security Policy

## Reporting a vulnerability

This is a personal/portfolio project: security issues should be reported
openly through the [GitHub Issues](https://github.com/rios-vini/internship-finder/issues)
tab, prefixed with `[security]` in the title.

There is no private reporting channel or bug bounty for this project.

## Scope

The project collects publicly available job postings from ATS platforms and
never stores credentials or personal data beyond what is already public on the
source sites. `data/` (collection outputs and SQLite history) is local and not
versioned.

## Supported versions

Only the current `main` branch is supported.
